## Phase 2 で確認できていないこと

- **iOS**: 開発環境が Windows のため、iOS では一切動作確認していない。
- **Expo Go での「端末に保存」**: `expo-media-library`(SDK 57)のネイティブ部分が Expo Go に含まれないため、保存は利用できない。この場合は共有から保存するよう案内する。開発ビルドでの確認結果は README / 作業報告を参照。
- **実写真での見た目**: 動作確認は合成した単色のテスト画像のみ。実際のコーデ写真での文字の読みやすさは未検証。
- **複数端末・画面サイズ**: Pixel 7 エミュレータ(API 35)1台のみ。

## 設計上の制約

- トリミングの位置を変えると、ラベルは写真ではなくキャンバスに対する相対位置で保持されているため、写真に対してずれる。ラベルを置く前にトリミングを決める想定(画面にも案内を表示)。
- 90°回転はラベル位置も一緒に回すが、ラベルの文字は回らない。
- 写真は取り込み時に長辺 3000px へ縮小し、JPEG(品質 0.92)で再エンコードする。EXIF(位置情報を含む)はこの時点で除去される。
- 書き出しは幅 1080px 固定。より高解像度の出力は未対応。
- 「元に戻す」の履歴は最大 100 件。アプリを終了すると編集内容は失われる(下書き保存は未実装)。
- パッケージ ID(`com.example.coordinate`)は仮の値。リリース前に変更が必要。
