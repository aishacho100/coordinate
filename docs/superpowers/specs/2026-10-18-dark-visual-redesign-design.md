# UI 刷新: ダーク・ギャラリー(文字を減らし、見た目で分かる)

2026-10-18。ユーザーが C 案(ダーク・ギャラリー)、アイコンは極細(A)を選んだ。
プレビュー: `.superpowers/brainstorm/11738-1792323619/content/`(dark-flow.html、icons-v3.html)。

## 目的
Instagram に載せる人が好む、洗練された見た目にする。説明文を減らし、アイコンと写真で操作が分かる UI にする。

## 決定済み
- 配色: 黒地(#0F0E0D)、文字は#F4F1EC、金(#C9B38A)は「いま押すもの」だけ。**ダーク固定**(ライトは廃止。端末の設定は無視)。※ユーザーは未回答だったため、C 案から私が決めた。変更したいときは言ってもらう。
- フォント: 見出し・ロゴは既存のまま(明朝、Cormorant)。本文はゴシック。
- アイコン: 線だけ・極細(線幅 1.2)。**絵文字は使わない。操作の文字ラベルも出さない**(アクセシビリティ用の読み上げ名は必ず付ける。長押しで小さな名前を出す)。
- 写真が主役。文字は写真の上に小さく乗せる。
- ホーム: キャッチコピーなし。ロゴ文字(仮: Coordinate。名前は保留)と「＋」だけ。
- 流れ: ホーム → 解析中(光る点) → 結果(写真に点とブランド名、下に切り抜きの一覧と探す/編集/削除) → 商品(画像カード、✓=同じ、≈=似ている) → 編集・共有(タグを写真に置く、道具はアイコン)。
- 例外(文字を残す): 画像検索の同意、外部への送信の説明、エラー、価格の出典と取得日、販売元、プライバシー。

## 範囲と順序
1. トークンと部品: `theme.ts`(ダーク固定)、アイコン部品(react-native-svg か既存の依存で。Expo SDK 57 の推奨に従って確認)、`AppButton`、`Screen`。
2. ホーム、解析中。
3. 結果(アイテムの一覧、候補カード、同意カード)。
4. 編集、書き出し、設定。
5. スクリーンショットで確認(エミュレータ。起動の前にユーザーへ確認する)。

## 守ること
- 既存テストの挙動(機能)は変えない。文言を変えるときはテストも直す。
- 読み上げ名、タップの大きさ(44pt 以上)、コントラストを守る。
- ボタンは全幅にしない(最大幅 280)。FAB は丸。
- 未実装を実装済みと言わない。見た目の確認は画像で行い、できなかった点は報告する。

## ホームの背景(決定: A2)
- 仮の写真: `apps/api/eval/photos/1647218947427-d783309440d2.jpg`(Unsplash、全身・キャップの人物)。公開前に、自前の写真か AI 生成へ差し替える(1ファイルの置き換えで済むようにする。モデルの権利のため、仮のままの公開は不可)。
- 加工(白黒): sharp で 840×1680 程度(長辺 1700px 以下)に cover で切り抜き(position: attention)、grayscale、linear(1.1,-8)、JPEG 品質 68 → `apps/mobile/assets/images/home-bg.jpg`(約 300KB 以下)。
- 重ね方: 画面全体に黒 rgba(15,14,13,.30)、上から黒のグラデーション(0%: .92 → 38%: .5 → 70%: 0)、下から黒のグラデーション(4%: #0F0E0D → 30%: .6 → 55%: 0)。グラデーションは `expo-linear-gradient`(SDK 57 の対応版を `npx expo install` で入れる)。
- ロゴ文字は上中央、Cormorant 斜体、字間広め、色 #E8DCC0。「＋」は下中央の金の丸(56pt)。
